# Wheel of Sakshi 🎡

A game-show spinning wheel for Sakshi's 24th birthday: 176 challenges across eight categories and three spice levels, with players, scoring, group votes, special birthday moments and a finale.

**Play it:** https://ankitamullagiri.github.io/wheel-of-sakshi/

- Everything runs in the browser. No accounts, no server.
- Edits and photos are saved in the browser you use. To move them between devices, use **Edit Game → Save & Share** to export and import.
- Photos you upload are never sent anywhere and are not part of this repo.
